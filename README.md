# network-management
A modern Internet Service Provider (ISP) management dashboard built with React. The application helps ISP operators monitor subscriber connectivity, manage internet subscriptions, and perform essential service operations through a centralized interface.

Features

Dashboard Overview

* Total registered subscribers.
* Online and offline subscribers.
* Paused internet services.
* Customer-reported issues.
* At-a-glance network statistics.

Subscriber Management

* View subscribers in a structured data table.
* Search customers by name or IP address.
* Filter subscribers by connection and service status.
* View individual customer details.
* Display internet plans and connection information.

Service Management

* Upgrade subscriber internet speed.
* Pause and resume internet services.
* Confirmation dialogs for important actions.
* Instant UI updates after successful operations.
* Toast notifications for user feedback.

Getting Started

Clone the repository:

git clone <repository-url>
cd isp-control-center

npm install
npm run dev
